# Nocturne 1.2 — исправленная структура Android-проекта

Главное исправление: исходники Kotlin перенесены из неверного каталога `App/SRC/main` в стандартный `App/src/main`, который использует Android Gradle Plugin. Добавлены две короткие встроенные WAV-мелодии. Workflow собирает именно модуль `:App`.

## Сборка через GitHub Actions
1. Загрузите содержимое этой папки в корень репозитория, сохраняя папку `.github`.
2. Убедитесь, что в репозитории есть `App/src/main/java/com/nocturne/app/MainActivity.kt`.
3. Откройте Actions → Build Nocturne APK → Run workflow.
4. После успешной сборки скачайте `Nocturne-debug-apk` в Artifacts.

APK пока требует проверки на физическом устройстве. Успешная компиляция сама по себе не гарантирует корректность всех функций и поведения на конкретной прошивке.
