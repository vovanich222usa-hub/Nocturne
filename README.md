# Nocturne 1.1 — Android

Нативное Android-приложение на Kotlin без платных библиотек и без серверной части. Все данные хранятся локально на телефоне.

## Что включено

- Ночной интерфейс: глубокий сине-графитовый фон, лавандовые акценты, мягкие карточки и нижняя навигация «Сегодня / Будильники / Планер / Напоминания».
- Будильники и напоминания: один раз, каждый день, будни, выходные, выбранные дни недели, каждую неделю, месяц, год, каждые N дней и каждые N часов.
- Настраиваемые дни недели, дата первого срабатывания, интервал и временное окно (начало/конец).
- Мелодии: две встроенные короткие мелодии Nocturne, системный звук будильника и выбор аудиофайла с телефона через системный файловый выбор.
- Вибрация, действие «Через 5 минут», подтверждение выполнения и повтор сигнала каждые 5 минут, пока разовое событие не подтверждено.
- Органайзер: задачи, события и заметки с датой, заметкой и отметкой «Готово».
- Локальное хранение, восстановление запланированных сигналов после перезагрузки и обновления приложения.
- Разрешение точных будильников и уведомлений запрашивается у пользователя при необходимости.

## Важно о циклах и условиях

«Временное окно» ограничивает время запуска: если выбранное время не попадает в окно, приложение переносит сигнал на начало ближайшего допустимого окна. В текущей версии окно корректно применяется для интервалов внутри одних суток (например, 08:00–21:00). Для ночного окна, пересекающего полночь, и сложных условий вида «только при подключении к Wi-Fi / геолокации / событии календаря» потребуется отдельный следующий этап разработки.

Android и производители телефонов могут ограничивать работу будильников в энергосбережении. После установки разрешите уведомления и точные будильники; для надёжной работы на некоторых устройствах также разрешите Nocturne автозапуск и фоновую работу.

## Сборка APK на Windows — бесплатный вариант

### 1. Скачать Android Studio

1. Откройте официальный сайт: https://developer.android.com/studio
2. Скачайте Android Studio (бесплатно) и установите с настройками по умолчанию.
3. При первом запуске выберите Standard setup. Дождитесь загрузки Android SDK.
4. В Android Studio откройте **Tools → SDK Manager**.
5. На вкладке **SDK Platforms** отметьте **Android 15.0 (VanillaIceCream) / API 35**.
6. На вкладке **SDK Tools** проверьте, что установлены **Android SDK Build-Tools 35.0.0**, **Android SDK Platform-Tools** и **Android SDK Command-line Tools**. Нажмите Apply.

### 2. Скачать Gradle 8.7

В комплекте нет Gradle Wrapper JAR, поэтому один раз установите Gradle отдельно:

1. Откройте https://gradle.org/releases/ и скачайте **Gradle 8.7 binary-only** (`gradle-8.7-bin.zip`).
2. Распакуйте, например, в `C:\Gradle\gradle-8.7`.
3. Откройте Windows «Изменение системных переменных среды» → «Переменные среды».
4. Создайте системную переменную `GRADLE_HOME` со значением `C:\Gradle\gradle-8.7`.
5. В системной переменной `Path` добавьте `%GRADLE_HOME%\bin`.
6. Откройте новое окно PowerShell и проверьте: `gradle --version`. Должна отображаться версия 8.7.

### 3. Открыть проект

1. Распакуйте `Nocturne-Android-Project-v1.1.zip` в обычную папку, например `C:\Projects\Nocturne`.
2. Запустите Android Studio → **Open** → выберите именно папку `Nocturne`, в которой находятся `settings.gradle.kts` и `build.gradle.kts`.
3. Если появится запрос доверия проекту, подтвердите.
4. В Android Studio откройте **File → Settings → Build, Execution, Deployment → Build Tools → Gradle**. В поле **Gradle JDK** выберите встроенный JDK 17 или другой JDK 17+.
5. Откройте вкладку **Terminal** внизу Android Studio. Убедитесь, что терминал находится в корневой папке проекта (рядом с `settings.gradle.kts`). Выполните:

   ```powershell
   gradle assembleDebug
   ```

6. Дождитесь `BUILD SUCCESSFUL`. При первой сборке Gradle скачает Android Gradle Plugin и зависимости, поэтому нужен интернет.

### 4. Где находится APK

После успешной сборки файл появится здесь:

`Nocturne\app\build\outputs\apk\debug\app-debug.apk`

Скопируйте APK на телефон любым способом: USB, облако или мессенджер. На телефоне откройте файл и разрешите установку приложений из этого источника, если Android спросит. Это debug-сборка для личной установки и тестирования.

### 5. Установка и первые разрешения

1. Откройте Nocturne.
2. Разрешите отправку уведомлений.
3. Если Android предложит перейти к разрешению «Будильники и напоминания» / «Точные будильники», включите его для Nocturne.
4. На Xiaomi, TECNO, Infinix, Huawei и некоторых других устройствах дополнительно разрешите автозапуск и работу приложения в фоне.
5. Создайте тестовый будильник на 2–3 минуты вперёд и проверьте звук, вибрацию и действия уведомления.

## Бесплатная сборка через GitHub Actions (без установки Android Studio на ПК)

В архив включён workflow `.github/workflows/android.yml`.

1. Создайте бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый пустой репозиторий, например `nocturne-android`.
3. Загрузите в него всё содержимое распакованной папки проекта, включая скрытую папку `.github`.
4. Откройте репозиторий → **Actions**. При первом запуске разрешите GitHub Actions.
5. Запустите workflow **Build Nocturne APK** кнопкой **Run workflow** (или отправьте commit в ветку main).
6. После завершения успешного запуска откройте страницу запуска workflow и скачайте артефакт **Nocturne-debug-apk** в разделе **Artifacts**. Внутри будет `app-debug.apk`.

GitHub Actions предоставляет бесплатные минуты для публичных репозиториев и ограниченный бесплатный лимит для приватных репозиториев; актуальные лимиты смотрите в настройках GitHub.

## Технические требования

- Android Studio актуальной версии.
- JDK 17 или новее.
- Gradle 8.7.
- Android SDK Platform 35 и Build Tools 35.0.0.
- minSdk 26 (Android 8.0), targetSdk 35.

## Ограничения и тестирование

Это доработанный исходный проект, но не сертифицированная сборка. APK не собран в этой среде: здесь нет Android SDK и Gradle distribution, а сетевой доступ для их загрузки недоступен. Перед повседневным использованием проверьте циклы, мелодии, восстановление после перезагрузки и энергосбережение на конкретном телефоне. Временное окно в версии 1.1 рассчитано на интервал, не пересекающий полночь. Для надёжного применения собственной мелодии Android должен сохранить доступ к выбранному аудиофайлу.
